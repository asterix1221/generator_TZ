# Создание технического задания

## Гостевой режим (без регистрации)

1. Откройте главную страницу приложения
2. Выберите **тип проекта**:
   - 🌐 **Web** — веб-приложение
   - 📱 **Mobile** — мобильное приложение
   - 🎮 **Game** — игра
   - 🏢 **Corp IS** — корпоративная система
   - 📄 **Other** — другое
3. Выберите **уровень сложности**:
   - **Базовый** — простой проект для начинающих
   - **Средний** — стандартный учебный проект
   - **Продвинутый** — сложный проект с интеграциями
   - **Профессиональный** — production-ready проект
4. Нажмите **«Создать техническое задание»**
5. ТЗ будет создано. В гостевом режиме оно не сохраняется.

> 💡 **Совет**: Зарегистрируйтесь, чтобы сохранять и редактировать свои ТЗ.

## Авторизованный режим

После входа в систему:

1. Перейдите в **«Мои ТЗ»** (личный кабинет)
2. Нажмите **«Создать новое ТЗ»**
3. Выберите тип и сложность проекта
4. Нажмите **«Создать»**
5. Вы будете перенаправлены на страницу редактирования ТЗ

## Структура ТЗ

Каждое техническое задание включает:

| Раздел | Описание |
|--------|----------|
| **Цель** | Основная цель проекта |
| **Описание** | Общее описание проекта |
| **Функциональные требования** | Список функций и возможностей |
| **Требования к БД** | Структура базы данных |
| **Стек технологий** | Рекомендуемые технологии |
| **Список фич** | Основные фичи проекта |

## Редактирование ТЗ

1. Откройте ТЗ из списка «Мои ТЗ»
2. Нажмите на название для редактирования
3. Изменяйте любые разделы
4. Автосохранение происходит через 2 секунды после изменений

## Удаление ТЗ

1. В списке «Мои ТЗ» нажмите **«Удалить»**
2. Подтвердите удаление в диалоговом окне
