# Генератор технических заданий

## Описание

Production-ready веб-приложение для автоматизации формирования структурированных технических заданий для учебных и студенческих проектов.

## Быстрый старт

```bash
# Клонирование репозитория
git clone <repo-url>
cd generator-tz

# Настройка переменных окружения
cp .env.example .env

# Запуск всех сервисов
docker-compose up --build
```

После запуска:
- **Приложение**: http://localhost:80
- **API документация**: http://localhost:8000/docs

## Возможности

- Генерация ТЗ без авторизации (гостевой режим)
- Регистрация и аутентификация пользователей
- 5 типов проектов: Web, Mobile, Game, Corp IS, Other
- 4 уровня сложности
- Экспорт в DOCX и HTML форматы
- Интеграция с Trello (JSON шаблон)
- Публичные ссылки для просмотра ТЗ
- Автосохранение изменений
