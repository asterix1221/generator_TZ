# Экспорт результата

## Форматы экспорта

После создания технического задания вы можете экспортировать его в различных форматах:

| Формат | Описание | Использование |
|--------|----------|---------------|
| **DOCX** | Microsoft Word документ | Для печати и редактирования |
| **HTML** | Веб-страница | Для публикации в интернете |
| **Trello JSON** | JSON файл | Для импорта в Trello |

## Экспорт из интерфейса

### Авторизованные пользователи

1. Откройте ТЗ из раздела «Мои ТЗ»
2. Нажмите кнопку **«Экспорт»** в верхней части страницы
3. Выберите нужный формат:
   - 📄 **DOCX** — скачать документ Word
   - 🌐 **HTML** — скачать HTML файл
   - 📋 **Trello** — скачать JSON для Trello
4. Файл автоматически загрузится на ваше устройство

### Гостевой режим

В гостевом режиме экспорт доступен на странице результата:
1. После генерации ТЗ нажмите **«Экспорт»**
2. Выберите формат
3. Файл будет загружен

## Использование DOCX

Скачанный файл `.docx` можно открыть в:
- Microsoft Word
- LibreOffice Writer
- Google Docs (загрузить файл)

Документ содержит все разделы ТЗ с форматированием.

## Использование HTML

HTML файл можно:
- Открыть в любом браузере
- Опубликовать на веб-сервере
- Отправить кому-либо

## Структура документа

Экспортируемый документ содержит:

```
Техническое задание
├── Название проекта
├── Тип проекта
├── Уровень сложности
├── Цель
├── Описание
├── Функциональные требования
├── Требования к базе данных
├── Стек технологий
└── Список фич
```

> 💡 **Совет**: Для импорта задач в Trello используйте формат Trello JSON.
