# 10.4.5 Public SharedLink и доступ по ссылке

## Цель
Предоставить другим пользователям доступ к ТЗ по публичной ссылке.

## Предпосылки
- Вы авторизованы.
- Открыто ТЗ, которым вы хотите поделиться.

## Шаги
1. Откройте нужное ТЗ.
2. Нажмите **Поделиться** (или аналогичную кнопку).
3. Скопируйте публичный URL.
4. Передайте ссылку адресату.

## Ожидаемый результат
- Адресат открывает страницу по URL вида `/shared/{token}`.
- Он может просмотреть содержание ТЗ.

## Возможные ошибки и что делать
- **Ссылка недействительна (404)**
  - Возможно, ТЗ удалено или токен устарел.
- **Нет доступа (401/403)**
  - Проверьте, что отправляете правильную ссылку.

> Примечание: доступ по SharedLink предназначен для чтения. Для изменения ТЗ нужен владелец/авторизация.
