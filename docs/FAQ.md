# Частые вопросы (FAQ)

## Общие вопросы

### Что такое Генератор ТЗ?

Это веб-приложение для автоматического создания структурированных технических заданий для студенческих проектов. Помогает быстро сформировать полноценное ТЗ с учётом типа проекта и уровня сложности.

### Какие типы проектов поддерживаются?

- 🌐 **Web** — веб-приложения
- 📱 **Mobile** — мобильные приложения
- 🎮 **Game** — игры
- 🏢 **Corp IS** — корпоративные системы
- 📄 **Other** — другие проекты

### Какие уровни сложности доступны?

| Уровень | Описание |
|---------|----------|
| Базовый | Простой проект для начинающих |
| Средний | Стандартный учебный проект |
| Продвинутый | Сложный проект с интеграциями |
| Профессиональный | Production-ready проект |

## Регистрация и вход

### Как зарегистрироваться?

1. Нажмите **«Регистрация»** на главной странице
2. Заполните форму: имя, email, пароль
3. Нажмите **«Зарегистрироваться»**

### Я забыл пароль, что делать?

Функция восстановления пароля временно недоступна. Создайте новый аккаунт с другим email.

### Сколько действует сессия?

Сессия JWT действует 24 часа. После этого потребуется повторный вход.

## Использование

### Нужно ли регистрироваться для создания ТЗ?

Нет, вы можете создавать ТЗ в гостевом режиме. Но авторизованные пользователи могут сохранять, редактировать и экспортировать свои ТЗ.

### Как сохранить ТЗ?

Зарегистрируйтесь и войдите в систему. Созданные ТЗ будут автоматически сохранены в вашем аккаунте.

### Что такое автосохранение?

При редактировании ТЗ изменения сохраняются автоматически через 2 секунды после последнего изменения. Индикатор показывает статус сохранения.

### Как удалить ТЗ?

1. Откройте список «Мои ТЗ»
2. Нажмите **«Удалить»** рядом с нужным ТЗ
3. Подтвердите удаление в диалоговом окне

## Экспорт

### В каких форматах можно экспортировать ТЗ?

- **DOCX** — документ Microsoft Word
- **HTML** — веб-страница
- **Trello JSON** — для импорта в Trello

### Как экспортировать в Trello?

1. Откройте ТЗ
2. Нажмите **«Экспорт»**
3. Выберите **«Trello»**
4. Скачайте JSON файл и импортируйте в Trello

## Публичные ссылки

### Как поделиться ТЗ?

1. Откройте ТЗ
2. Нажмите **«Поделиться»**
3. Создайте публичную ссылку
4. Скопируйте и отправьте ссылку

### Можно ли редактировать ТЗ по публичной ссылке?

Нет, публичная ссылка предоставляет доступ только для чтения.

### Как удалить публичную ссылку?

1. Откройте ТЗ
2. Перейдите на вкладку **«Поделиться»**
3. Нажмите иконку удаления рядом со ссылкой

## Технические вопросы

### Какие технологии используются?

| Компонент | Технология |
|-----------|------------|
| Frontend | React 18, TypeScript, Tailwind CSS |
| Backend | Python 3.11, FastAPI |
| Database | PostgreSQL 16 |
| Cache | Redis 7 |

### Как запустить приложение локально?

```bash
docker-compose up --build
```

Приложение будет доступно по адресу http://localhost:80

### Где найти API документацию?

После запуска: http://localhost:8000/docs

## Ошибки

| Ошибка | Решение |
|--------|---------|
| «Пользователь с таким email уже существует» | Используйте другой email |
| «Неверный email или пароль» | Проверьте данные и попробуйте снова |
| «Требуется авторизация» | Войдите в систему |
| Ошибка подключения к базе данных | Проверьте запущены ли контейнеры Docker |
