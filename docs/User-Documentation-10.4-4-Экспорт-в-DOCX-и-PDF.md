# 10.4.4 Экспорт в DOCX и PDF

## Цель
Скачать сгенерированное ТЗ в виде файлов DOCX или PDF.

## Предпосылки
- У вас открыто существующее ТЗ.
- Вы авторизованы (обычно доступ к экспорту есть и для автора, и для контекстов, где ТЗ доступно).

## Экспорт в DOCX
### Шаги
1. Откройте нужное ТЗ.
2. Нажмите **Скачать DOCX**.

### Ожидаемый результат
- Начинается загрузка файла **.docx**.

### Ошибки
- **Сетевая ошибка**
  - Обновите страницу и попробуйте снова.

## Экспорт в PDF
### Шаги
1. Откройте нужное ТЗ.
2. Нажмите **Скачать PDF**.

### Ожидаемый результат
- Начинается загрузка файла **.pdf**.

### Ошибки
- Если PDF не формируется:
  - повторите попытку;
  - проверьте доступность сервера.

> Примечание: генерация PDF выполняется сервером (WeasyPrint). В некоторых средах возможны ограничения, поэтому при сбое сервер может вернуть ограниченный/упрощённый результат.
