# Публичная ссылка

## Обзор

Публичные ссылки позволяют делиться техническими заданиями с другими людьми без необходимости предоставлять им доступ к вашему аккаунту.

## Создание публичной ссылки

### Для авторизованных пользователей

1. Откройте нужное ТЗ из раздела «Мои ТЗ»
2. Нажмите кнопку **«Поделиться»** (иконка 📤)
3. В появившемся окне нажмите **«Создать публичную ссылку»**
4. Скопируйте сгенерированную ссылку
5. Нажмите **«Копировать»** или поделитесь напрямую

Ссылка имеет формат:
```
https://generator-tz.com/public/{token}
```

## Доступ по публичной ссылке

Любой пользователь, имеющий ссылку, может:
- Просматривать ТЗ в режиме чтения
- Экспортировать ТЗ в DOCX или HTML
- Создать копию ТЗ в свой аккаунт

### Ограничения

По публичной ссылке **нельзя**:
- Редактировать ТЗ
- Удалять ТЗ
- Создавать новые версии

## Управление ссылками

### Просмотр активных ссылок

В разделе «Мои ТЗ»:
1. Откройте конкретное ТЗ
2. Перейдите на вкладку **«Поделиться»**
3. Здесь отображаются все созданные ссылки

### Удаление ссылки

1. Нажмите на вкладку **«Поделиться»** в ТЗ
2. Нажмите иконку 🗑️ рядом с ссылкой
3. Подтвердите удаление

> ⚠️ **Важно**: После удаления ссылки она перестаёт работать.

## Безопасность

- Ссылки содержат уникальный токен
- Токен невозможно угадать
- Срок действия ссылок не ограничен
- Вы можете удалить ссылку в любой момент

## Пример использования

1. Студент создаёт ТЗ для дипломного проекта
2. Создаёт публичную ссылку
3. Отправляет ссылку научному руководителю
4. Научный руководитель просматривает ТЗ и оставляет комментарии
