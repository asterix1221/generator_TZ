# 10.4.2 Выбор типа проекта и уровня сложности

## Цель
Определить параметры генерации ТЗ: тип проекта и сложность.

## Предпосылки
- Вы авторизованы в системе.
- Открыта главная страница/страница генерации.

## Шаги
1. Выберите **Тип проекта** из списка:
   - Web
   - Mobile
   - Game
   - Corp IS
   - Other
2. Выберите **Уровень сложности** (1–4).
3. Нажмите **Сгенерировать ТЗ**.

## Ожидаемый результат
- Создаётся новое ТЗ.
- ТЗ появляется в интерфейсе и может быть просмотрено/отредактировано.

## Возможные ошибки и что делать
- **Поля не заполнены**
  - Выберите тип и сложность и повторите генерацию.
- **Слишком много запросов (429)**
  - Подождите указанное время и повторите запрос.
