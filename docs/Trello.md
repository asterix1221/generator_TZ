# Интеграция с Trello

## Обзор

Экспорт в формате Trello JSON позволяет импортировать задачи из технического задания в Trello для удобного управления проектом.

## Получение JSON файла

1. Откройте нужное ТЗ
2. Нажмите **«Экспорт»**
3. Выберите **«Trello»**
4. Скачайте файл `.json`

## Импорт в Trello

### Способ 1: Power-Up (рекомендуемый)

1. Создайте новую доску в Trello
2. Нажмите **«Power-Ups»** в меню доски
3. Найдите **«Import»** и добавьте его
4. Выберите **«Import from JSON»**
5. Загрузите скачанный файл
6. Задачи появятся на новой доске

### Способ 2: Trello Import Power-Up

1. Откройте https://trello.com/import
2. Выберите **JSON** как формат
3. Загрузите файл
4. Выберите целевую доску

### Способ 3: Через Butler (автоматизация)

1. Скачайте JSON файл
2. Откройте доску в Trello
3. Нажмите **«Automation»** → **«Rules»**
4. Создайте правило для создания карточек из JSON

## Структура данных

Экспортируемый JSON содержит:

```json
{
  "name": "Название ТЗ",
  "lists": [
    {
      "name": "Функциональные требования",
      "cards": ["Требование 1", "Требование 2"]
    },
    {
      "name": "Задачи",
      "cards": ["Задача 1", "Задача 2"]
    }
  ]
}
```

## Списки по умолчанию

| Список | Содержимое |
|--------|------------|
| **Функциональные требования** | Все требования из ТЗ |
| **База данных** | Таблицы и сущности |
| **Технологии** | Технический стек |
| **Фичи** | Основные функции проекта |

## Пример работы

1. Студент создаёт ТЗ для веб-приложения
2. Экспортирует в Trello JSON
3. Импортирует на доску Trello
4. Получает готовую структуру задач
5. Назначает исполнителей и сроки

## Ограничения

- Только задачи, не доски
- Нет связей между карточками
- Нет меток и уведомлений

> 💡 **Совет**: После импорта добавьте метки, сроки и участников вручную.
